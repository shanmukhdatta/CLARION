REPRODUCIBLE RELEASE

Deploy without overstating readiness

GitHub Pages hosts only this static introduction. Actual investigations run on a local or authorized offline Linux workstation.

Developer quickstart

git clone https://github.com/shanmukhdatta/CLARION.git
cd CLARION
python -m pip install -e . -r requirements-v4.txt -r requirements-demo.txt
python scripts/submission_demo.py run --out artifacts/submission_demo --cases 10
python scripts/release/check_submission.py --run artifacts/submission_demo/investigation
clarion serve --run artifacts/submission_demo/investigation --port 8000

Optional: install a compatible PyTorch and PyTorch Geometric build for GraphSAGE. Install MLflow only when local experiment tracking is desired.

GitHub Pages is not the backend. No wallet/IP evidence, model checkpoint, tokens or private investigator data is transmitted or hosted here.
